This is a simple keyboard based on the ESP32-S3. It features seven keys for the scale, alongside three additional keys for adjusting the octave. The seven keys are the main way to play, and they always play the notes of the scale. The three additional keys do not play notes themselves. They only change how high or low the seven keys sound. This keeps the keyboard simple, because the player does not need more keys to reach higher or lower notes. The same seven keys can be used for the whole range, just in a different octave.
The key on the left of the three keys is for lowering the octave, and the key on the right is for increasing the octave. Each press moves all seven keys down or up by one octave, so the whole scale shifts together. The middle key simply resets the keyboard octave. Pressing the middle key brings the keyboard back to its normal octave, no matter how many times the left or right key has been pressed. This makes it easy to return to the starting point without having to count how many steps up or down have been taken, and it also makes it easy to recover if the wrong octave key is pressed by mistake.
It also includes a joystick and an OLED screen, which together serve the purpose of implementing automatic background chords. The background chords play on their own behind the melody, so the player does not have to play the chords by hand while also playing the melody. The OLED screen displays the current chord, so the player can always see which chord is playing at that moment. The joystick allows you to make adjustments to the chord itself. Moving the joystick changes the chord, and the screen updates to show the new chord straight away. This means the player can change the harmony while playing, without stopping, and without needing extra keys or buttons for the chords.
Finally, an LED is included as a quality-of-life feature to show the current beat and indicate which functions are currently active. The LED flashes in time with the beat, so the player can see the rhythm as well as hear it. It also shows when a function is active, so the player does not have to guess whether the background chords are on, or whether the octave has been changed. Together, the seven keys, the three octave keys, the joystick, the OLED screen, and the LED make a keyboard that is simple to use, but still gives the player control over the octave, the chords, and the beat, all without making the keyboard complicated to learn or play.
