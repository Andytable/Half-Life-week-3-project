This is a simple keyboard based on the ESP32-S3. It features seven keys for the scale, alongside three additional keys for adjusting the octave. It also includes a joystick and an OLED screen, which together serve the purpose of implementing automatic background chords. The OLED screen displays the current chord, while the joystick allows you to make adjustments to the chord itself. Finally, an LED is included as a quality-of-life feature to show the current beat and indicate which functions are currently active.
